# Saving and scenes

Vista saves your scene as you work, a moment after each change. There is no save button.

## Switching scenes

Choose **Open scene** in the **Scene** menu to see your scenes and open one.

| | Button | Does |
|---|---|---|
| {icon:PencilAlt} | **Rename** | Renames that scene. |
| {icon:Copy} | **Duplicate** | Copies that scene. |
| {icon:Trash} | **Delete** | Deletes that scene. |

**New scene** makes an empty scene and opens it. {icon:FolderOpen} **Open scenes folder** shows your scene files.

Undo starts fresh each time you open a scene.

## Where scenes are saved

The first time you open Vista, it asks where to save. Vista makes a folder called vistaxiv inside the folder you choose. Each scene is a file named after it, in the scenes folder inside vistaxiv. To share a scene, share its file. To use a scene someone sent you, put its file in that scenes folder.

**Select save folder** in the **Scene** menu changes where Vista saves.

## The demo scene

Vista adds a scene called Demo - Limsa to your save folder, to show what a finished scene looks like. It is set in Limsa Lominsa, so open it there, choose Live and press {key:Play}. It is yours to change or delete, and Vista won't add it to that folder again.
